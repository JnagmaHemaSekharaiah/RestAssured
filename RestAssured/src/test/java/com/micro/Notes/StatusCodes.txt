2XX - SUCCESS STATUS CODES - SERVER SUCCESSFULLY RECEIVED UNDERSTOOD AND PROCEED THE REQUEST
------------------------------------------
200 - OK            - REQUEST IS SUCESSFULLY
201 - CREATED       - NEW RESOURCES SUCESSFULLY CREATED
202 - ACCEPTED      - REQUEST IS ACCEPTED FOR PROCEESING BUT NOT YET COMPLTED
204 - NO CONTENT    - REQUEST IS SUCCESSFULL BUT THERE IS NOT RESPONSE BODY


 4xx - CLIENT ERROR
 -----------------
400 - BAD REQUEST            - REQUEST IS INVALID (INCORRECT SYNTAX OF JSON)
401-  UNAUTHORISED           - AUTHENTICATION IS MISSING
403 - FORBIDDEN              - SERVER UNDERSTAND REQUEST BUT HAVE NOT PROCEED YET.
404 - NOT FOUND              - INCORRECT URL, END POINT IS NOT PRESENT
405 - METHOD NOT ALLOWED     - INCORRECT HTTP METHOD
406 - NOT ACCEPTABLE         - SERVER CAN'T PROVIDE REQUESTED RESPONSE FORMAT [CLIENT REQUEST UNSUPPORTED FORMAT]
408 - REQUEST TIMEOUT        - SERVER WAITED TOO LONG FOR REQUEST [CLIENT TAKES TOO LONG TO SEND DATA]
409 - CONFLICT               - TRYING TO CREATE A RECORD IF ALREADY EXIST
415 - UNSUPPORTED MEDIA TYPE - PAYLOAD FORMAT IS UNSUPPORTED [ACTUAL : JSON EXPECTED:XML]
422 - UNPROCESSABLE CONTENT  - VALIDATION/SYNTAX IS VALID BUT DATA FAILS VALIDATION/BUSSINESS RULES{AGE LIMIT,INVALID DOMAIN}
429 - TOO MANY REQUESTS      - USER SEND TOO MANY REQUEST IN THE GIVEN AMOUNT OF TIME

5XX - SERVER ENCOUNTERED A PROBLEM WHILE PROCESSING A VALID REQUEST - SERVER SIDE ERROR
-------------------------------
500 - INTERNAL SERVER ERROR      - SERVER ENCOUNTERED UNEXPECTED CONDITION
501 - NOT IMPLEMENTED            - DEOES NOT IMPLEMENTED IN THE SERVER SIDE
502 - BAD GATEWAY                - THE GATEWAY/PROXY COULD NOT GET A PROPER RESPONSE FROM THE SERVER IT WAS COMMUNICATING WITH
503 - SERVICE UNAVILABLE         - THE SERVER IS TEMPORRARLY UNABLE TO HANDLE THE REQUEST [MAINTAINCE,OVERLOAD,SERVICE IS DOWN]
504 - GATE WAY TIME OUT          - THE PROXY/GATEWAY SERVER DID NOT RECEIVED ESPONSE FROM UPSTREAM SERVER ON TIME
505 - HTTP VERSION NOT SUPPORTED - SERVER DOESN'T SUPPORT REQUEST HTTP VERSION (CLINET REQUESTS UNSUPPORTED HTTP VERSION)
